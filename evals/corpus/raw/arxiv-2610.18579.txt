When such a model picks the wrong action, there
is no chain of thought to read. The error has two
very different explanations. The model may have
misread what the agent already knows, for example by missing that the last action failed or losing
track of what it holds; or it may have read all of it
correctly and still chosen badly. The first points to
the state representation or the context budget, the
second to the decision itself. Final-action accuracy
cannot tell these cases apart, and generated rationales need not reflect the computation behind an
answer (Turpin et al., 2023; Lanham et al., 2023).
Conversely, a correct action does not show that the
model understood the trace.
We therefore ask, behaviorally: can System One
models understand the information an agent has
obtained and act correctly on it, and when they
fail, can we tell failures of comprehension from
failures of decision? On a single agent decision
state we ask, each in isolation, the next-action question and factual probes whose answers the environment determines, such as whether the last action
succeeded, what the agent carries, or whether an
action is permitted. Crossing “all measured facts
correct” with “action correct” gives four observable
outcomes (Figure 1). Around this measurement
we build a frozen benchmark of 65,228 records,
19,663 of them paired test states, from simulators
with exact ground truth (ALFWorld, BabyAI-Text,
TextWorld), customer-service policies (τ 2 -bench),
tool use, web navigation and coding traces, with
every admissible action in context and gold labels
computed only from what the agent has seen. We

System One models choose an agent’s next action by scoring a supplied set of options in a
single pass. This makes them fast and cheap,
but when they choose wrongly there is nothing to inspect: did the model misread what the
agent has seen, or read it correctly and still act
wrongly? We answer behaviorally. On a frozen
benchmark of agent decision states from simulated environments, customer-service policies,
tool use, web navigation and coding, we pair
every next-action question with factual probes
about the same state, each answered independently. Across seventeen fast systems and a reasoning model, the answer is consistent: most
wrong actions follow correct reading, and the
more accurate a system, the more of its errors
take this form. These errors are not noise; they
gather on the same states across systems of
every kind. Where the probed facts provably
determine the action, models that read every
fact still fail to combine them, and their own
answers, composed by code, repair the failure.
On real states, what is missing is often not a
fact but the next sub-goal.

An agent acting in an environment repeatedly reads
the feedback of its previous actions, works out
where it stands, and chooses what to do next. In

Kwok et al., 2026; Palmer, 2026; Convai Innovations, 2026; Cloudflare, 2026). Given the agent’s
state and a set of candidate answers, they return a

Measuring Comprehension and
Decision on the Same State

2.1

Decision states

A decision state s consists of a task goal, the executed history of actions and the observations they
produced, any rules that govern the environment or
policy, and the set A(s) of admissible next actions.
The model must choose one element of A(s) and
is never asked to generate an action. Every admissible action is placed in context with its name and a
description, nothing is shortlisted, and no language
model proposes candidates; tool calls with open
arguments are enumerated from the environment
or database. Gold is a set G(s) ⊆ A(s) computed
only from information available to the agent: in the
simulators, the first actions of all shortest plans on a

Factual probes

On annotated states we also ask closed factual
probes whose answers the simulator state, database
or data labels determine: the outcome of the last action, the agent’s location and inventory, completed
subgoals, whether an action is permitted, and which
observation establishes a fact. Each question, probe
or decision, is answered on the state alone; several
may share a request, but no question or answer is
added to another question’s input and no gold fact
is revealed. “Paired” means that the input state is
identical, not that we observe stages of the model’s
computation.

Benchmark

The frozen benchmark has 65,228 records, 59,234
test and 5,994 dev (Table 6 in Appendix C). Most
paired states come from three simulators with exact ground truth: ALFWorld, BabyAI-Text and
TextWorld cooking games (Shridhar et al., 2021;
Paglieri et al., 2025; Chevalier-Boisvert et al., 2019;
Carta et al., 2023; Côté et al., 2018; Cui et al.,
2025). Trajectories are rolled out by each environment’s expert, by a noisy variant and by a variant that issues invalid commands, so traces contain failures and detours; no language model takes
part. Gold sets were checked against breadth-first
search in the real environments. From τ 2 -bench airline and retail (Barres et al., 2026) we take policyconstrained states with tool calls enumerated from
the database and probes on record fields and permissions. Tool selection, web navigation and AgentRM trees (Xu et al., 2026; Shi et al., 2025; Patil
et al., 2025; Ross et al., 2025; Deng et al., 2023; Xia
et al., 2025) carry probes on fields stated in the trace
(the visible-field probes), and 360 coding records
built from real repository histories ask which edit
caused a regression and which limited next action
follows. Ladders vary trace length, distance from
the decisive observation and novelty, and confirmation cohorts generated later from new seeds re-test
the findings on states no earlier run had seen. A

Reading Correctly Is Not Enough

We first ask how often measured comprehension
and action correctness come apart, how costly the
errors are, and whether they are idiosyncratic to a
model or attached to particular states.
5.1

Most decision errors follow correct
reading

Table 2 and Figure 3 give the four outcomes for all
eighteen systems on the same 19,663 states. For the
six most accurate systems, 73–85% of all decision
errors occur on states where every measured fact
is answered correctly. Conditional on all measured
facts being correct, the action is still wrong in 10–
21% of states. The converse also holds: when at
least one fact is answered wrongly, the action is
nevertheless correct in 62–70% of states. Neither
direction of the pairing is a reliable proxy for the
other.
The share of errors that follow correct reading
grows with accuracy (Figure 3b). Among the fast
systems above 0.5 accuracy it ranges from 49%
(Kev-9B) to 81% (Gemma), and it is 85% for the
reasoning reference, GPT-6.1. Stronger systems
mainly stop misreading; they do not stop choosing wrongly after reading correctly. Deliberation
helps: GPT-6.1 raises decision accuracy to 0.884,
7 points above Gemma and 9–12 points above the
three most accurate System One models (Eikos27B, Clef and JEV), at about 70 times JEV’s cost
per state (§4). But its remaining errors are of the
same kind, and in an even larger proportion. CLM8B, Laya and Quyet-1.0-Large rarely answer both
